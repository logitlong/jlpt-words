# 无敌绿宝书 N1 背单词

一个打开就能用的 JLPT N1 背词网页，不用注册，也不用安装。

**立即使用：https://weilong-lab.github.io/n1-word-book/**

## 特色

- **完整词库**：4,692 个 N1 单词，按 40 个单元排列
- **连续长线声调**：用整条高低线画出每个词的声调，并标出声调类型
- **真实发音**：每个词都有牌组录音
- **重写的词条**：分条中文释义、日文解释和例句，共 6,407 条例句，都能点击收听
- **N1 真题形式练习**：约 18,000 道题，覆盖漢字読み、文脈規定、言い換え類義、用法
- **科学复习**：用 FSRS 算法安排复习时间，每天新词数量可自己设定
- **手机、平板、电脑都好用**：触屏全屏背诵，电脑上一屏看完，支持深色和浅色模式

## 怎么学

### 背单词

在“今日”页点“开始学习”，会先复习到期的词，再学新词。也可以在“单元”页选一个单元从头背。

学习方式有三种：

| 方式 | 正面显示 | 适合 |
| --- | --- | --- |
| 认词 | 单词 | 看词想意思 |
| 听音 | 发音 | 练听力 |
| 回想 | 释义 | 看意思想单词 |

翻面后选“认识”或“不认识”，系统会据此安排下次复习。单元可以按牌组分，也可以自定义每组 10～200 个词。

### 速刷

只显示单词和发音，按空格或点屏幕切到下一个，适合快速过一遍。

### 测验

- **真题测验**：题型和 N1 考试的文字词汇部分一致
- **单词测验**：汉字、读音、释义两两组合出题

可以选题数，也可以自定义；可以只做未做过的题或错题，错题能一键加入生词本。题目字号能调，每台设备分别保存。

## 手机和平板

- 背诵时点屏幕任意位置看答案
- 看到答案后，点空白处再听一遍发音
- 用 Safari 打开网址，点“分享”，选“添加到主屏幕”，之后就能像 App 一样全屏使用；学过的内容没网也能打开

## 电脑快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 翻面；翻面后再按一次算“认识” |
| `D` | 不认识 |
| `R` | 听发音 |
| `F` | 已熟悉，不再安排复习 |
| `S` | 加入生词本 |
| `Z` | 撤销上一步 |
| `←` `→` | 浏览词表时翻词 |
| `Esc` | 关闭 |

## 学习进度保存在哪里

进度只保存在你当前使用的浏览器里，不会上传到任何服务器，也不需要账号。

这也意味着换设备或清理浏览器数据时，进度不会自动跟过去。请在设置里点“导出进度”保存备份，到新设备上用“恢复进度”导入。主屏幕上的 App 和浏览器的数据也是分开的。

词库和音频在第一次使用时下载，之后保存在设备上。
